# SAB 2026 supplementary material

`SAB2026_supplement.pdf` contains Supplementary Sections A--E for
*Interoceptive Attention as Dynamic Homeostatic Prioritization in a Foraging
Agent*. These sections were not part of the 12-page camera-ready proceedings
paper. The accepted manuscript itself is not included in this repository.
